# Security Policy

## Supported Versions

Security updates are provided for the latest published minor version of VGraph packages.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by emailing [visactor@bytedance.com](mailto:visactor@bytedance.com).

Include as much detail as possible, such as affected package versions, reproduction steps, impact, and any available proof of concept. The maintainers will review the report and coordinate a fix before public disclosure when appropriate.
