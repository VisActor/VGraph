# 关系图

关系图数据是一种更一般化的网络数据，不同于 DAG 图的拓扑排序特性，关系图表达的内容更加自由和复杂。它存在于生活的方方面面，自然的反映着现实世界，如生物基因网络、社交好友网络等。

## Demo - 社交关系

### 数据释义

社交关系是人与人之间的互动，两人之间可能互相认识或者不认识，可能是亲密无间，也可能只是泛泛之交，这其中存在着复杂的关系网络。demo 中选取了《悲惨世界》一书中的人物关系数据，其中提供了人物名称、类别以及相互之间的联系次数等数据。

### 场景编码

**布局：** 力导布局。

**元素：** 图中的每个节点代表《悲惨世界》书中的一个人物，节点颜色映射人物所处类别；节点之间的连线表示两者之间存在社交联系，边的宽度则代表了联系的深浅；边越宽，则说明该边所连接的两个人物之间亲密度越高。
 
**交互：** 

1. hover 节点：展示该节点代表的人物名称
2. click 节点：高亮节点相邻节点，展示该人物所认识的全部人物
3. drag 节点：拖拽节点改变节点位置，允许用户自主调整社交关系网络布局
4. click 图例：筛选某一类别的人物群体，聚焦观察该群体内部之间的社交联系
5. click 画布：清空视图交互，恢复初始状态，允许用户重新探索社交网络数据
6. Toolbar ：
   1. 寻找节点之间最短路径（快捷键：shift + click ）：选择两个节点，高亮两者之间的最短路径，帮助探索这两个人物之间潜在的社交关系
   2. 好友筛选图标（快捷键：alt + click）：选择一个节点，高亮与其相连节点之间连线宽度超过某一具体数值的节点，帮助寻找该人物的好友关系

**组件：**

1. Tooltip ：与 ‘hover 节点’ 交互搭配使用，呈现节点内容
2. Toolbar ：放置了‘寻找节点路径’和‘好友筛选’的交互图标
3. Legend ：说明节点颜色所代表的对应人物类别

### 设计思考

* 在力导布局中每个粒子之间具有斥力，每个相连的粒子之间又具有引力，从初始的随机无序的布局不断演变，逐渐趋于平衡稳定；常用于描述事物之间的关系，是无向图布局的经典方式之一。
* 社交关系图中的连线代表了人物之间的联系，因而将代表联系权重的数值映射到了线的宽度上，象征着岌岌可危抑或是坚不可摧的社交联系。两者之间的搭配相辅相成，促进用户的感知。
* 在寻找节点之间相连路径的交互中，只为用户匹配了节点之间的最短路径，这也是与交互目标相关。当两个人之间通过其他人介绍认识时，中间人越少，这种方式被采用的机率越大。因此在进行具体交互实现时，结合任务目的来实现的方案有效性更强。
