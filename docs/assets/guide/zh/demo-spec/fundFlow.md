# DAG 图

DAG (Directed Acyclic Graph) 是有向无环图。在图论中，如果一个有向图从任意顶点出发无法经过若干条边回到该点，则这个图是一个有向无环图。

## Demo - 基础有向图 

### 数据释义

基础有向图中选取了公司资金流转的数据，展示事物的运转流程。

### 场景编码

**布局：** 基于 DAGLayout 的层次布局。

**元素：** 图中的每个节点表示公司的一笔资金，节点之间的有向边表示公司每笔资金之间的流向关系；入度表示资金的流入，出度表示资金的流出；只有出度的节点代表公司的初始资金，只有入度的节点则表示公司资金最终的去向。
 
**交互：** 

1. hover 节点：高亮了节点的起止路径，表示该笔资金从最初流入公司到最后输出的全过程。

### 设计思考

* DAGLayout 布局与树图布局类似却又不同，树图只允许每个节点有一个来源节点，但在有向无环图中一个节点可以有多个来源节点，因而任何有向树图都是有向无环图，但是有向无环图未必是有向树图。
* Darge 布局由于其严密的拓扑性质，具有很强的流程表达能力，在有先后顺序限制的场景中应用广泛。
