# 树状图

树状图是一种特殊形式的节点链接图，通常用于展示层次数据，着重表达个体之间的层次关系。其中，层次关系主要表现为包含和从属两类。

## Demo - 行政区划 

### 数据释义


地域划分也是一种层次数据，如地球包括七大洲，每个州又包含若干个国家。行政区划 demo 中数据选取了中国省市县三级行政区划的数据。

### 场景编码

**布局：** 紧凑树布局。

**元素：** 图中的每个节点代表一个行政区，节点之间的连线表示两者之间的层次关系；具体而言，整个视图从左向右的水平延伸是行政区划之间的包含关系，连线左侧的行政区域包含了连线右侧的行政区域。
 
**交互：** 

1. pan + zoom 画布：视图导航，便于浏览和观察数据
2. hover 叶子节点：高亮节点的起始路径，回溯该行政区域的从属关系
3. click 节点：展开/收起该节点，对整体行政区划数据进行按需查看

### 设计思考

* 大尺度的层次结构数据由于屏幕尺寸的限制，无论采取何种布局方式都无法有效的呈现全部信息。“焦点 + 上下文”技术是一种解决方案，重点呈现用户关心的数据，同时简要的表现上下文信息。如 demo 中最初只展示了一级行政区划的数据，用户可以通过点击展开需要探索的子树，从而提高整体空间的利用效率，有效的呈现信息。
* 紧凑树布局虽然能在有限的空间内展示更多的节点，但是子节点全部展开时会看不清某个子节点的归属。因此展开的子树会用特殊颜色做统一的标识，能根据颜色看清某个城镇属于哪个省。当展开到县级别时还可能看不清归属的城市，hover 节点高亮起止路径可以帮助查看这一细节。
* 行政区划数据中，每一级行政区下都划分了数量较多的行政区域；为了避免用户繁琐的统计步骤，在所有非叶子节点的节点后附上了当前节点拥有的子节点数量，从而帮助用户把握整体的行政区划结构。
