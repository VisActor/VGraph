# 关系图

关系图数据是一种更一般化的网络数据，不同于 DAG 图的拓扑排序特性，关系图表达的内容更加自由和复杂。它存在于生活的方方面面，自然的反映着现实世界，如生物基因网络、社交好友网络等。

## Demo - 交通网络

### 数据释义

交通节点和道路特征的组合形成了交通网络。demo 中选取了 Sioux-Falls 的交通数据，数据中包含每个路口的经纬度坐标和道路的长度、通行量、容量等信息。

### 场景编码

**布局：** 交通路口的经纬度坐标映射。

**元素：** 图中的每个节点一个交通路口，节点之间的有向边表示路口之间的联通道路，道路的通行是单向的，箭头的方向表示道路的通行方向，边的长度代表两个路口之间的距离，边的颜色深浅代表了当前实际通行数量的规模。
 
**交互：** 

1. hover 边：Length 表示该条道路的长度，Cost 表示通行所需要的时间
2. click 画布：清空视图交互，恢复初始状态，允许用户重新探索交通网络
3. Toolbar ：
   1. 耗时最短图标（快捷键：shift + click ）：选择两个路口，高亮两者之间的通过时长最短的路径，解锁耗时最少的方案
   2. 距离最短图标（快捷键：alt + click ）：选择两个路口，高亮两者之间的距离最短的路径，解锁距离最短的方案

**组件：**

1. Tooltip ：与 `hover 边` 交互搭配使用，呈现边的内容
2. Toolbar ：放置了‘耗时最短’和‘距离最短’的交互图标

### 设计思考

* 交通数据中一般带有对应节点的地理坐标信息，这可用于空间布局；与现实空间坐标一致的布局方案，可以减少用户的认知负担。
* 在道路通行一般划分了左右车道用于往返，并且往返车道具有不同的通行信息。为了避免道路连线的遮挡，以及曲线连接引发的道路通行路线的误解，demo 中为每个路口指定了连线接入和输出的位置，从而保证路线的分离。
