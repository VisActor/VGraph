# 树状图

树状图是一种特殊形式的节点链接图，通常用于展示层次数据，着重表达个体之间的层次关系。其中，层次关系主要表现为包含和从属两类。

## Demo - 文件架构 

### 数据释义

计算机文件系统中的文件和目录是一个典型的层次结构，用来帮助人们组织和认知信息。文件架构 demo 中选取了 Flare 可视化工具库的文件架构作为数据来源，它描述的是该工具库中各类文件夹和文件之间的从属关系。

### 场景编码

**布局：** 径向生态树布局。

**元素：** 图中的每个节点表示文件目录下的一个文件夹或者具体文件，节点之间的连线表示两者之间的层次关系；整体树图起点位于视图中心，其他节点依次向外延伸，内层节点包含了所连接的外层节点，最外层的叶子节点代表的是具体文件。
 
**交互：** 

1. pan + zoom 画布：视图导航，便于浏览和观察整体结构
2. hover 节点：高亮了节点的起止路径；通过回溯该文件夹/文件的根源，并且追踪其后续内容，呈现该文件夹/文件在整个目录中位置。
3. click 节点：收起/展开该节点，对整体文件架构进行整理便于观察
4. drag 节点：拖拽节点至其他节点改变层级结构，帮助调整规划整个文件目录架构

### 设计思考

* 径向树布局可以克服空间浪费的问题。根节点位于圆心，不同层次的节点放置在半径不同的同心圆上，越外层同心圆越大，可以容纳更多的节点。整个布局呈现圆形，合理的利用了空间。
* 文件架构数据中最外层的叶子节点是承载了实际内容的代码文件，它们都具有直接的实质意义；因此 demo 整体使用了生态树的布局方式，将这群具有实质意义的文件统一分布在最外层的同心圆上，从而加强它们之间的相关性，便于用户识别。
