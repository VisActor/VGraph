# DAG 图

DAG (Directed Acyclic Graph) 是有向无环图。在图论中，如果一个有向图从任意顶点出发无法经过若干条边回到该点，则这个图是一个有向无环图。

## Demo - 分组有向图

### 数据释义

分组有向图中选取了数据分析流程数据。该数据中将数据分析过程依次分为四个大阶段，每个阶段下又各有不同的步骤来实现。

### 场景编码

**布局：** 数据固定的布局方式。

**元素：** 图中的节点被包含在四个分组内，表示数据分析的四个阶段；其中每个节点表示数据分析过程的一个步骤，节点之间的有向边表示每个步骤之间的联系；节点的入度是该分析步骤的输入，节点的出度则是完成该分析步骤后的产出；只有出度的节点是数据分析最开始的目标，只有入度的节点则是经过数据分析之后得到的结果。
 
**交互：** 

1. hover 组：高亮分组及其组内的元素，帮助识别该分组的内容，表示数据分析在该阶段内需要完成的步骤
2. hover 边：高亮边连接的入度和出度节点，表示该边连接的分析步骤，展示所处的上下文关系
3. hover 节点：高亮节点在分组内的起止路径，展示节点在该分组阶段内的位置，表示数据分析步骤的上下文的关系

### 设计思考

* 分组数据中根据节点数据的具体含义可以搭配不同的组间节点连线行为：组到组连线 / 组间节点到节点连线。在本场景中，数据分析每个步骤节点均有对应的上下文节点关系，因此选择了组间节点之间的连线关系。
* 在该场景中数据为分组节点提供了固定的横纵网格布局，为了避免节点连线之间的斜向关系破坏已有布局，图中选取了 hLine / vLine 的水平 / 垂直拐线来与分组节点布局相匹配，从而提升视觉的协调性。
