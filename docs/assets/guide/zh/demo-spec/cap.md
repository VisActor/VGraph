# 树状图

树状图是一种特殊形式的节点链接图，通常用于展示层次数据，着重表达个体之间的层次关系。其中，层次关系主要表现为包含和从属两类。

## Demo - 思维导图 

### 数据释义

思维导图是一种用图像整理信息的图解；整体布局从中央关键词出发，向外以辐射线形连接所有相关的字词、想法、任务等。思维导图 demo 中选取了六顶思考帽与产品规划关系的数据，该数据中简化了六顶思考帽的思维特征，从产品规划的角度对其进行定义和梳理。

### 场景编码

**布局：** 脑图布局。

**元素：** 图中的每个节点表示一个关键词，节点之间的连线表示两者之间的关联；demo 中从中央“六顶思考帽”的关键词出发，向左右两边依次发散关联相应关键词。
 
**交互：** 

1. hover 节点：高亮了节点的起止路径，展示当前关键词所处的整个关联链路，从起始节点扩展到当前关键词，又以当前关键词为基准向外发散至外层叶子节点。
2. click 节点收起/展开图标：收起/展开该节点，对整体思维架构进行整理便于观察
3. drag 一级节点：拖拽节点改变当前节点的排序位置，用于帮助调整六顶思考帽与产品设计流程的关系

### 设计思考

* 思维导图中每个关键词节点都有着相应含义，并且每一层级的节点之间可能存在某种联系；我们可以根据这些信息为节点进行样式和颜色的选择，从而增强可读性。如六顶思考帽关键词与颜色相关，demo 中为每顶思考帽对应的子类节点赋予了相应的颜色；并且为了区分层级结构，图中为每一层级节点选取了不同的节点样式，直观的展示了各层节点和全部关键词节点代表的含义。
* 当节点的 icon 可能与连线重叠的时候可能会产生一些视觉上的误差，这时候推荐给 icon 配置一个背景将二者区分开。
