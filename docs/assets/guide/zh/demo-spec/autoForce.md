# 智能布局关系图

## 场景介绍
力导向布局是广义图的一种通用展示形式。在力导向图中，通过连线连接的节点来表示两个实体的联系。力导向图常用来展示关系网络。

在真实的业务场景下，往往需要展示多种类型的节点，甚至多种类型的连线。在此场景下，用户往往关注两个层次的信息：
- 看整体：看数据的分布，哪些节点之间联系更紧密，哪个节点的影响力最大等。
- 看个体：在看整体结构以后往往会定位到感兴趣的节点做进一步分析，这时候要看个体的详细数据和直接关联等。


## 设计思考
在此场景下，数据规模无法提前预知，可能是稀疏数据，也可能是很稠密的数据。稀疏数据下界面简洁，节点之间关系明确，因此采用了全量展示，hover 节点高亮关系的形式。而如果是万级的稠密数据，容易产生部分区域连线过多，看不清节点的整体分布，展示不流畅等问题，于是我们默认会将连线隐藏。当用户定位到个体时，通过点击节点高亮展示与之直接关联的节点和连线。另外在此场景下，如何清楚定位一个节点也是个问题。调研得知在定位到节点以后，通常会去看节点的细节和直接关联，如果在很小的缩放比时不够清晰，而如果定位好以后让用户去放大视图也难保证焦点不丢失。因此在定位时我们做了 放大和平移动画，将节点移动到视窗中心，再给此节点加动画的方式来突出此节点，方便识别和后续操作。

## 场景编码
**布局**: 在此场景下，关系网络的规模，特性无法事先确定。由于图的分布效果完全取决于配置参数，力导向图布局有一定的使用门槛。并且数据集特性不同时，即使是一套配置参数也无法保证布局效果很好。因此 VGraph 根据多种规模和特性的数据集研发了[自动配置力函数](../layout-spec/force#自动配置力函数)。

<br/>


**元素**: 用图形的颜色来区分不同种类的数据是一种常用的映射手段，但是用什么颜色却大有学问。配色需要有一定辨识度，美观，饱和度不宜过高避免长时间使用眼疲劳，饱和度也不能过低造成低分辨率显示屏上看不清。VGraph 精心打造了以下色板，效果经过业务长时间考验。
<p style="text-align:center;"><img src="/images/docs/guide/palette.png" width="600"></p>

在很多业务场景下，连线也是有分类的。展示连线的分类，大家很容易就想到在连线上配置文本标签展示。这种方式在 DAG 图中用得很多，在力导图上则不然。理由是力导图可能会有一些连线密集的区域，文本标签基本不可读。加之在力导图场景下节点之间距离不固定，因此文本和连线的长度不一定匹配，美观度不够好。调研了解用户虽然有事也看连线分类，但主要还是看节点的，不应喧宾夺主。因此本场景下也用颜色来展示连线分类，在高亮关系时会在连线上展示文本标签。考虑到节点的颜色多样，连线的颜色用灰色梯度来展示。
<p style="text-align:center;"><img src="/images/docs/guide/gradient_palette.png" width="450"></p>
由于连线颜色分类相对较少，从最浅颜色开始导致默认视图太浅也不便做进一步的分析。因此采用明暗间隔的方式来做最终呈现。

<br/>

**交互**:
- click 切换数据：切换图中展示数据，可以体验在不同量级数据之下的表现。
- click 连线隐藏/展示：隐藏/展示图中连线。
- click 定位节点：定位 id 为输入框值的节点，焦点动画。
- click 节点：大数据量时高亮关系。
- hover 节点：小数据量时高亮关系。
